# Quickstarts

Try ClauZ3 by asking an agent to do a small task, reviewing its guarantees,
and approving the result. Both guides put chat and approvals together in the
browser, with a terminal alternative.

| Start here | What you will see |
| --- | --- |
| [Mock email](quickstarts/mock-email.md) | An agent proposes an email, ClauZ3 proves recipient and call limits, and you approve a mock sender. No email is sent. |
| [Real file work](quickstarts/real-files.md) | Install a library, approve a file write, inspect the file, and count its lines. |

The mock email guide uses a bundled example whose sender does nothing. Its
**Declared mock** label is an author declaration, not an enforced sandbox.
Both guides use the real proof and approval workflow.

For the ideas behind the workflow, see [Concepts](explanation/concepts.md)
and [How ClauZ3 compares](explanation/comparison.md). For launch options and
session lifetime, see the [CLI reference](reference/cli.md).
