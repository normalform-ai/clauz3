# Intro video from a real example

## Status

Not started. The README GIF and the docs video show the email approvals
tutorial, whose sender is a declared mock (`just docs-videos`).

## Idea

Record a short introduction built on a real example instead: a task with
visible consequences, such as a file write in a project
([real file work](../quickstarts/real-files.md)), where the approval card
states limits a reader cares about and the result can be checked afterwards.
