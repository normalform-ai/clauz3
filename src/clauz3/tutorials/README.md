# Bundled tutorials

These are deliberately small, runnable templates shipped in the wheel.
`email/` is a curated copy of part of `examples/email/`; the examples remain
the fuller developer collection. Test these templates independently rather
than synchronizing their contents with examples. Keep walkthrough prose in
`docs/quickstarts/`; only short contextual help and agent guidance belong here.

The UI creates a persistent working copy in its user data directory. It never
executes the installed package's template in place. Reset replaces that working
copy and clears only that tutorial's conversations and approval preferences.
