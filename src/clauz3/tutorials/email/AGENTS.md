# Email approvals tutorial

Use only the installed mock email library for this tutorial. Its sender does
nothing: no email is delivered and there is no simulated outbox. Proofs,
approvals, and receipts are real. Explain that distinction to the user.

Discover the library's contracts and submit a program for proof and approval.
For the introductory request use `only`, `at_most`, and `unique_recipients`.
Do not substitute a real sender or install another library to deliver email.
